ODent45

Open source dental implant surgical planning addon for Blender 4.5 LTS

Complete workflow from DICOM data to surgical guide design

Overview

ODent45 is an open source Blender addon designed for dental implant surgical guide planning. It provides a complete digital workflow for dental professionals, from importing CBCT/DICOM scans to designing custom surgical guides ready for 3D printing.

What is a Surgical Guide?

A surgical guide is a 3D-printed template that fits over the patient's teeth or edentulous ridge, containing sleeves that guide drill bits during implant surgery.

  • Precise implant positioning
  • Reduced surgical time
  • Minimal invasiveness
  • Predictable outcomes
Trusted by professionals

Tested in over 500 cases with satisfactory results. Built by dental experts for the community.

Features

DICOM Import & Visualization
  • Import DICOM series from CBCT scans
  • 3D image files (.nrrd, .mha)
  • Point Cloud – interactive 3D with threshold filtering
  • Textured Slices – stacked planes
Interactive 2D Slices (MPR)
  • Axial, Coronal, Sagittal orientations
  • Real-time update
  • Threshold color overlay
  • Brightness/contrast controls
  • Slice flip & rotation
Mesh Generation
  • Marching Cubes isosurface extraction
  • VTK-powered
  • Adjustable threshold (-400 to +3000 HU)
  • Custom segmentation colors
Implant Planning
  • FDI tooth number selection
  • Implant diameter & length
  • Abutment (stock/custom)
  • Sleeve configuration
  • Visual toggles: sleeve, cutter, axis, abutment, safe zone
Surgical Guide Design
  • Splint geometry generation
  • Tube/cylinder guides
  • Custom guide parts & cutters
  • Finalization for 3D printing
Additional Tools
  • Mesh repair (decimate, clean, remesh)
  • Cutting (path split, ribbon cut, frame cut)
  • Alignment tools
  • Model base & undercut preview

Installation

Method 1: Install from File
  1. Download ODent45.zip
  2. Open Blender 4.5
  3. Edit → Preferences → Add-ons
  4. Click Install and select the zip
  5. Enable the addon
Method 2: Portable Version
  1. Download from Telegram support group
  2. Ready for use (Windows, Linux)
All dependencies and modules are pre‑configured.

Prerequisites

Software
  • Blender 4.5 LTS
  • Windows 10/11, macOS, Linux
Python Dependencies (auto‑installed)
  • SimpleITK – DICOM reading
  • VTK – Visualization Toolkit
  • numpy, opencv-python, scipy

Linux users: Wine is optional for auto‑align features.

Workflow

  1. Create/Open Project – File → New Project
  2. Load DICOM – Set folder path, choose visualization, click Read DICOM
  3. Navigate Slices – In Odent Slicer workspace, move the Slices Pointer
  4. Generate Mesh – Adjust threshold (bone ≈ 600–800 HU), set color, click DICOM to Mesh
  5. Matching & Blocked Model – Import IOS/dental scan, fix mesh, align with DICOM mesh, make blocked model
  6. Plan Implant – Add Implant, select tooth, configure parameters, add teeth
  7. Design Guide – Add Guide Splint or custom tubes, add components, Finalize Guide Geonodes
  8. Export – Select guide object, File → Export → STL

FAQ

After install, the addon will display a warning panel. Click Install Odent modules and set preferences.

Check that the threshold is not too high and that your DICOM data is valid.

Ensure you're in the "Odent Slicer" workspace. Select the Slices Pointer object and move it.

Make sure the mesh is selected and active before exporting.
